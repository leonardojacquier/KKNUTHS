CQ CURAMIX PM  
 Agente curativo  
  
  
 CQ CURAMIX PM es un producto líquido a base de agua que mejora el curado del hormigón. se aplica  
 sobre la superficie del hormigón fresco formando una película uniforme, evitando la evaporación  
 Impacto repentino del agua de mezcla de hormigón. De esta manera el hormigón completa su proceso de  
 cura con la mayor humedad posible para una correcta hidratación del cemento.  
  
  
 PROPIEDADES Y VENTAJAS:  
  
 Fácil aplicación;  
 Se puede aplicar a áreas internas y externas;  
 Protege el hormigón de climas cálidos y calurosos;  
 Permite una mejor hidratación del cemento;  
 Reduce la formación de grietas por secado;  
 Reduce la contracción del hormigón;  
 Aumenta la durabilidad del hormigón.  
  
  
 CAMPOS DE APLICACIÓN  
  
 CQ CURAMIX PM se recomienda para uso en:  
 Hormigones de gran superficie expuesta, tales como: losas, pavimentos, etc.;

 MÉTODO DE APLICACIÓN  
  
 CQ CURAMIX PM debe aplicarse sobre la superficie de hormigón fresco inmediatamente después de la desaparición del  
 agua de exudación, que se produce entre media y dos horas después de alisado el hormigón. Esto también depende  
 Clima y tipo de hormigón.  
  
  
 CQ CURAMIX PM debe aplicarse mediante pulverizador para obtener una aplicación  
 homogéneo.  
  
  
 En piezas premoldeadas, CQ CURAMIX PM se puede aplicar inmediatamente después del desmolde para un mejor curado y  
 Desarrollo de resistencia mecánica.

RECOMENDACIONES  
  
Se recomienda homogeneizar el producto antes de su uso, especialmente cuando se almacena para  
algún tiempo.  
Se recomienda proteger de la lluvia la aplicación de CQ CURAMIX PM.  
Para tener una mejor retención de agua en el hormigón, se recomienda que el control de calidad  
CURAMIX PM se aplica en dos manos cruzadas.  
Producto listo para usar. No requiere dilución.  
  
  
RETIRADA DEL PRODUCTO:  
Después del período de curado deseado, es posible retirar la película creada por CQ CURAMIX PM  
usando agua caliente y cepillando la superficie, o usando un limpiador de alta presión.  
Recomendamos que nunca se use ácido, ya que las soluciones ácidas no eliminarán el  
membrana de curado, pero atacará el hormigón.  
  
  
 PRECAUCIONES, TRANSPORTE Y SEGURIDAD:  
 Producto clasificado como transporte no peligroso.  
 Producto no inflamable y no explosivo.  
 Utilice EPI apropiado: guantes, botas impermeables, gafas de seguridad química;  
 No ingerir, evitar el contacto prolongado con la piel y ojos;  
 No beber, comer ni fumar durante la manipulación; lávese las manos antes y después de un descanso  
 trabajo.
