# Estratégia e Moat

**Moat ≠ segredo de código.** Defesas reais: dados + memória + distribuição +
velocidade.

1. **[[Calibração por Showdown]]** — único moat estrutural: composto, cresce
   com uso, invisível a quem copia interface. Copiar a ideia não copia os dados
2. Memória do aluno (caderno, evolução, KB) — custo de troca
3. Velocidade de iteração (deploy 2min, feedback→produção no mesmo dia)
4. Marca: Motor KKN + KKN Tilt Detector (registrar no INPI junto com KKNuths)

## Política de comunicação
- Publicar RESULTADOS (o quê), manter MECANISMOS implícitos ("aprende com a
  base"), PARÂMETROS secretos (likelihoods, priors, limiares, calibration.json)
- Segredo de feature visível é ilusão — concorrente vê tudo criando conta
- Nobel: sempre "baseado na ciência que ganhou o Nobel", nunca "premiado"

## Posicionamento vs concorrência
GTO Wizard responde "o que o equilíbrio faz"; HUDs respondem "o que aconteceu";
KKNuths responde "o que provavelmente é verdade sobre ESTE vilão/aluno, com
quanta confiança, e quanto vale em dinheiro".
